How to interpret this run

Important context before quoting the numbers

Repeat-run variation

A separate audio run on 9 Nov, using the same recorded code fingerprints, scored 16/18 crop + mandi slots. The 10 Nov run shown here scored 18/18. This variation is a reason to avoid presenting 100% as a stable general accuracy figure.

Language coverage

This evaluation covers Punjabi and Punglish only: 9 clips in each group. Hindi-mixed input is experimental and was not validated by this 18-clip run. Replies are generated in Punjabi.

Data coverage

The local Agmarknet snapshot ends around March 2026 and contains price records for potato, onion and tomato. Market coverage is uneven; these results do not establish the accuracy of today's live mandi prices.

What the test represents

Prepared read-aloud questions, first-turn scoring, and 18 clips. Speaker identities and recording conditions were not fully documented in the run metadata. Spontaneous farmer speech, noisy market audio and other devices remain untested.

Read the score with its uncertainty. 18/18 corresponds to an approximate 95% Wilson interval of 82–100%. That interval is wide because the sample is small. The test checks recognition of the requested crop and mandi plus the agent's expected response status; it does not prove the underlying price record is current or correct. Earlier runs and field tests should be retained alongside this result.
